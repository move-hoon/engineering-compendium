## 배치 기준

일반적인 자료구조와 계산 원리를 다룹니다. 특정 엔진·런타임에서 구현되는 동작은 그 주제의 문서로 연결합니다.

문서는 개념, 문제, 해결 기법과 선택 근거를 중심으로 작성합니다. 구현·실험은 해당 문서 가까이에 두며, 기술별 탐색은 [기술별 목차](../indexes/technologies/)에서 연결합니다.
